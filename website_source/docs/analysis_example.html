In this section, we will explore some analysis examples that can be performed using the emln package. In this section, we will present two examples: node-level analysis and mesoscale analysis.

Node-level analysis with data from Kefi 2016

on this level, we will perform a comparison of the betweenness centrality scores for each state node, obtained using the get_igraph function, to the centrality scores of the same nodes in a supra-adjacency matrix (SAM) using the get_sam function. The betweenness centrality is a measure of the importance of a node in a network based on the number of shortest paths that pass through it. By comparing these scores layers seperatly and the SAM as one layer, we can gain insights into the differences in the network structure captured by each method.

This example demonstrates the use of emln to explore differences in centrality metrics across network layers and the importance of considering multilayer interactions in ecological network analysis.

Creating a Multilayer Object

Before we can calculate the betweenness centrality score of each state node, we need to create a multilayer object from the data. This is a node-aligned multiplex network with three layers: trophic interactions, non-trophic positive interactions, and non-trophic negative interactions. For more information on how to create a multilayer object from real data, please see the “Example with real data from Kefi 2016” section.

Betweenness Centrality

We will now calculate the betweenness centrality score of each state node using the two different methods:

Method 1: SAM of Multilayer Network

The first method involves calculating the betweenness centrality score of each state node using a SAM of the multilayer network.

# get the SAM
sam_multilayer <- get_sam(multilayer = multilayer_analasis, bipartite = F, directed = T, sparse = F, remove_zero_rows_cols = F)

# converting sam to igraph object
graph_sam <- graph_from_adjacency_matrix(sam_multilayer$M,mode = "directed",weighted = NULL,diag = TRUE,add.colnames = NULL,add.rownames = NA)

# betweeness of sam
eigen_sam <- igraph::eigen_centrality(graph_sam, directed = T, scale = T)$vector

Method 2: Per-Layer Calculation

The second method involves calculating the betweenness centrality score of each state node on a per-layer basis.

# get a list of igraph objects as layers igraph 
g_layer <- get_igraph(multilayer_analasis, bipartite = F, directed = T)

# betweeness of igraph layers
eigen_igraph = c()
for (layer in g_layer$layers_igraph){
  eigen_igraph <-append(eigen_igraph, igraph::eigen_centrality(layer, scale = T)$vector)
}
