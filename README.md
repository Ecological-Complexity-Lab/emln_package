# What is this repo for
This repository was the development repository of the emln package, which has its own public repository [https://github.com/Ecological-Complexity-Lab/emln](https://github.com/Ecological-Complexity-Lab/emln). 

**Starting 13/9/2023 the development is only on the package repo.**

This repository is still active because it contains the website that accompanies the emln repository, and this website will be actively updated as necessary and remain here.

# Folders

- **`website_source`**: All files for the emln package website.
- **`package`**: All files for the emln package (not active).
- **`docs`**: The active website files.
- **`data`**: All files needed for the development of the data in the package.
