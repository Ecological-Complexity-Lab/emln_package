# What is this repo for
This repository is the development repository of the emln package, which has its own public repository [https://github.com/Ecological-Complexity-Lab/emln](https://github.com/Ecological-Complexity-Lab/emln). For now, we develop the code here and move it to the public repository. **The package is then built in the emln repository.** At a later stage (likely after publication) we will continue development only on the package repo.

This repository also contains the website that accompanies the emln repository, and this website will be actively updated as necessary and remain here.

# Folders

- **`website_source`**: All files for the emln package website.
